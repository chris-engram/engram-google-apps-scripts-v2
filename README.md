# Engram Google Apps Scripts V2

## Overview
Enhanced automation scripts for Google Workspace, providing advanced functionality for:
- Google Sheets automation
- Gmail management
- Google Drive operations
- Calendar integrations
- Forms processing

## Project Structure
```
├── src/                 # Source code
│   ├── sheets/         # Google Sheets scripts
│   ├── gmail/          # Gmail automation scripts
│   ├── drive/          # Google Drive scripts
│   ├── calendar/       # Calendar scripts
│   └── utils/          # Shared utilities
├── docs/               # Documentation
├── tests/              # Test files
└── examples/           # Example implementations
```

## Getting Started
1. Clone this repository
2. Set up Google Apps Script project
3. Deploy scripts to your Google Workspace

## Development
- Branch from `dev` for new features
- Submit PRs to `main` for production releases
- Follow conventional commit messages
